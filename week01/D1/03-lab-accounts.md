# Day 1 实验 — 账号总动员

**时长：** 25分钟 | **轨道：** T2

---

## 学生指令（放屏幕上）

```
☑ GitHub       → 浏览器打开 github.com，登录（或用现有账号）
☑ Claude 桌面  → 打开 Claude 桌面应用，确认能对话
☑ Cowork       → 打开 Cowork，确认能看到文件系统
☑ WeChat 群    → 扫码进「AI+X Elite 20」班级群
☑ 课程仓库     → 接受 elite20-starter 仓库邀请（检查邮箱/GitHub通知）
```

---

## TA 指令

### 巡视清单
- [ ] 有人卡在 GitHub 密码？→ 帮他们重置，或用手机 GitHub App 扫码登录
- [ ] 有人 Claude 桌面没装？→ 记录名字，课后帮装
- [ ] 有人 Cowork 打不开？→ 检查是否最新版，重启试试
- [ ] 有人没收到仓库邀请？→ 当场重发

### 关键原则
> **识别 + 记录 + 课后处理。不要为了 1 个人拖住 19 个人。**
> 在花名册上打标记：✅ 全部通过 / ⚠️ 某平台有问题 / ❌ 未到场

---

## 经济学教授提示
- 这个环节看起来是纯技术操作，但它给学生一个**所有权感**：这些是你的工具了
- 可以类比：「第一堂经济学课，你拿到教科书、激活在线题库、注册 FRED 数据账号——今天是数字版的这个过程」
- 如果有学生提前全部完成，给他一个挑战：用 Claude 问一个经济学问题，看回答质量如何
