# Day 1 反思模板 — reflections/D1.md

---

## 学生指令（最后5分钟）

> 打开任意文本编辑器，写3行。不要多想，不要修饰。3行，3分钟，提交。

## 模板

```markdown
# D1 反思 — [你的名字]

1. 今天以前，我以为 AI 是 ______。今天之后，我觉得 AI 可能是 ______。
2. 在我的经济学学习/教学中，我最想让 AI 帮我做的一件事是 ______。
3. 第一天最让我意外的一件事是 ______。
```

## 提交方式

1. 在你电脑上任意位置新建一个文件夹叫 `Elite20_<你的名字>`
2. 在里面建子文件夹 `reflections`
3. 把上面这段内容保存为 `D1.md`
4. 先不用提交到 GitHub —— D3 我们一起做

---

## 教师备忘
- **不评分、不批注、不纠正。** 只检查"有没有交"。
- 这是学生第一次写反思——如果门槛太高，后面每天都会抗拒。
- 如果有人问我"写不出来怎么办"——回答："就写'我写不出来'就行。这是第零级反思。"
- 这些反思是 D8 做 3D 坐标卡时的原始素材，不要丢。
