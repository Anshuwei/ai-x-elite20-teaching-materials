# Day 3 教学指南 — "你的实验笔记本：GitHub"

**时长：** 60分钟 (Hook 5 + Lecture 20 + Lab 30 + Close 5)
**涉及轨道：** T3 (GitHub) + T2 (Agent技术栈)

## 教学目标
- 学生理解 Git/GitHub 的核心概念（仓库=笔记本，提交=标日期的一页）
- 每个学生成功 fork 课程仓库、clone 到本地、做第一次提交并 push
- **核心瓶颈是 SSH/PAT 认证这一步，不是 Git 概念**

## 教学节奏

| 环节 | 时长 | 教师动作 | 学生动作 |
|------|------|----------|----------|
| Hook | 5 min | 展示研究者的纸质实验记录 vs GitHub 提交记录截图 | 观察类比 |
| Lecture | 20 min | 四个类比讲完 GitHub 核心概念 | 理解概念 |
| Lab | 30 min | 逐步骤引导：fork → clone → 复制文件 → commit → push | 动手操作 |
| Close | 5 min | 让学生打开自己的 GitHub 仓库，欣赏自己的提交 | 确认提交在线可见 |

## 关键提醒
- **提前打印 SSH/PAT 速查表，人手一份。**
- 这个环节最容易发生"所有人都在等那一个同学配好 SSH key"——不要让这种情况发生
- 如果5分钟内 SSH 配不好，立刻切到 PAT 方式（用 gh CLI 已登录的 token）
- 经济学点缀：commit 历史 = 研究透明度和可复现性的基础设施——就像经济学论文里的数据和代码附录
