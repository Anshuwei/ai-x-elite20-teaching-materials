# Day 2 实验 — 搭建你的工作坊

**时长：** 35分钟 | **轨道：** T2 + T5

---

## 学生指令（分步，每步等大部分学生跟上再继续）

### Step 1 — 创建工作台（5分钟）

在你的电脑上创建文件夹：

```
桌面/Elite20_<你的名字>/
```

或终端：

```bash
mkdir ~/Desktop/Elite20_<你的名字>
```

### Step 2 — 挂载到 Cowork（5分钟）

1. 打开 Cowork
2. 找到"挂载文件夹"或"Add workspace folder"
3. 选择你刚才创建的 `Elite20_<你的名字>` 文件夹
4. 确认挂载成功（Cowork 界面会显示文件夹已连接）

### Step 3 — 烟雾测试（15分钟）

在 Cowork 中输入以下提示词（**一字不差**）：

> "在我的工作区创建一个 hello.md 文件，里面写：'Hello from [你的名字]的AI工作坊！今天是2026年4月。这是我人机协同的第一步。'"

观察 Agent 是否：
- ✅ 在文件夹中创建了 hello.md
- ✅ 文件内容正确
- ✅ 能告诉你它做了什么

### Step 4 — 截图（5分钟）

1. 在文件夹里找到 `hello.md`，打开看内容
2. 截图（能看到文件名 + 文件内容）
3. 保存截图到 `Elite20_<你的名字>/screenshots/D2-hello.png`

### Step 5 — 故障排除（如果卡住）

| 症状 | 可能原因 | 解决 |
|------|----------|------|
| Agent 说"我不能创建文件" | 文件夹未正确挂载 | 检查 Cowork 设置 → 重新挂载 |
| Agent 说"我没有看到工作区" | 权限未授予 | 检查 Claude 的文件夹访问权限 |
| Cowork 找不到 | 版本太旧 | 更新 Cowork 到最新版本 |
| 文件创建了但内容不对 | 提示词不够精确 | 复制上面的提示词重新运行 |

## 经济学教授提示

- 工作区文件夹可以类比为「个人研究文件夹」——每个经济学研究者都有自己的数据和代码目录，AI 工作区是同一个习惯的延伸
- 如果班上有些学生提前完成，让他们试试这个经济学主题变体提示词：
  > "在我的工作区创建一个 economic-concepts 文件夹，里面生成一个 supply-demand.md 文件，用 markdown 画出供需曲线的基本模型。"
