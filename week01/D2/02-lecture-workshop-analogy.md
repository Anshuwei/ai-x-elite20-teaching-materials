## 四要素详解

### 1. 工作台 = 你挂载的文件夹

| 工作坊概念 | AI 对应物 | 功能 |
|-----------|----------|------|
| 工作台（bench） | 工作区文件夹（workspace folder） | Agent 能读写的文件都在这 |
| 你在工作台上摆放材料 | 你放入文件夹的 PDF、CSV、图片 | Agent 可以看到和操作 |
| 你做好的东西放在工作台上 | Agent 写入文件夹的输出文件 | 会话结束后产物还在 |

> **关键观念：Agent 不是孤立聊天。它有眼睛可以看到你的文件，有手可以创建和修改文件。**

### 2. 墙上工具 = MCP / 连接器

| 工作坊概念 | AI 对应物 | 功能 |
|-----------|----------|------|
| 墙上挂的工具（扳手、锯子） | MCP 工具、API 连接器 | 让 Agent 与外部世界交互 |
| 每种工具专干一种活 | 每个 MCP server 提供一批工具 | 查数据库、发消息、搜网页 |

> **第一周不涉及 MCP 配置。但让学生知道这些"挂着的工具"存在。** 类比：第一堂木工课，你能看到墙上有锯子，但不急着用。

### 3. 食谱书 = Skills

| 工作坊概念 | AI 对应物 | 功能 |
|-----------|----------|------|
| 夹在墙上的食谱卡 | SKILL.md 文件 | 告诉 Agent 某种任务怎么做的标准流程 |
| 食谱写着"菠萝蛋糕怎么做" | SKILL.md 的 name + description | Agent 识别什么任务该用这个 Skill |
| 食谱里的步骤 | SKILL.md 的 body（指令正文） | Agent 执行时的规范 |

> **Day 5 你会让学生实际翻开一张食谱卡。今天是先看到墙上挂着"食谱书"这个东西。**

### 4. 学徒 = Agent（Claude）

| 工作坊概念 | AI 对应物 | 功能 |
|-----------|----------|------|
| 学徒 | Claude Agent | 执行任务的主体 |
| 学徒的技能水平 | 模型能力 | 理解、推理、生成 |
| 你给学徒派活 | 提示词（prompt） | 告诉 Agent 做什么、怎么做、验收标准 |

> **关键转折：你不是在"用软件"——你是在"带学徒"。带学徒的核心不是命令得对不对，而是你给的信息够不够、验收标准清不清楚。**

## 经济学教授可选的深层类比

> **生产函数视角：Y = A · f(K, L, H)**
> - K（物质资本）= 你的工具（Claude桌面、MCP连接器）
> - L（劳动力）= 你的 attention + Agent 的"劳动"
> - H（人力资本）= 你的经济学知识（X domain）+ Agent 的 Skills
> - A（全要素生产率）= 你和 Agent 协作的效率，这正是 K-S-T-A-R 要提升的
>
> **AI+X 精英班的本质：通过提升 A（人机协同效率），用同样的 K 和 L 获得更多产出。**
