# Day 2 Hook — 同一句话，三个环境，三种结果

**时长：** 5分钟 | **方式：** 现场演示

---

## 演示脚本

### 使用的提示词（同一个）

> "请整理近10年中国GDP增长率数据，做简要分析。"

### 三个环境

| 环境 | 操作 | 预设结果 |
|------|------|----------|
| **A. 网页版 Claude** | 在浏览器中打开 claude.ai，粘贴提示词 | 通用回答，数据可能过时，无个性化 |
| **B. Claude 桌面** | 打开 Claude 桌面应用，粘贴同样提示词 | 可能稍好，但也只能根据训练数据回答 |
| **C. Cowork + 工作区** | 在 Cowork 中挂载包含 GDP 数据的 CSV/Excel 文件，粘贴同样提示词 | 读取文件中的实际数据，给出精确分析 |

### 演示要点（边说边做）

1. "看，三句完全相同的话。"
2. 分别展示三个回答（提前准备好，但假装实时）
3. 放大环境 C 的回答："它读了我文件里的数据——这就是区别。不是 AI 更聪明了，是**环境给了它上下文。**"
4. 收束："今天你们要做的就是搭这个 '环境 C' ——你自己的 AI 工作坊。"

---

## 经济学教授备注
- 这个演示很自然地引出「信息不对称」——AI 和你的对话质量取决于它能看到什么信息
- GDP 数据案例可以换成你手头有的任何经济学数据文件，效果更真实
- 如果你有中国统计年鉴的截图、World Bank API 输出、或 FRED 数据，都可以作为"环境 C 里的文件"
