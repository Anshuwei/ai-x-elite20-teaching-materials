### Step 2 — 先读 SKILL.md（5分钟）

**在你调用 Skill 之前**，先找到并阅读对应的 SKILL.md 文件。

在课程仓库的 `skills/` 目录下找（或由教师告知位置）。

读的时候关注：

### Step 3 — 调用 Skill，执行任务（20分钟）

#### 选项 A — docx: 生成教学大纲

```
【身份】你是一位有10年经验的经济学教授，正在准备新学期《宏观经济学原理》课程。

【任务】使用 docx skill 创建一个教学大纲文档。

【输出形状】一个 .docx 文件，包含：
  - 课程名称、学期、学时、教师信息
  - 每周教学主题（16周）：从 GDP 核算 → IS-LM → AD-AS → 菲利普斯曲线 → 开放经济 → 增长理论
  - 每章推荐阅读（指定 Mankiw 或 Blanchard 对应章节）
  - 成绩构成：期中30% + 期末40% + 平时30%
  - 文件命名：syllabus-macro-2026.docx

【验收标准】
  - 文件在课程仓库中创建
  - 章节安排符合标准经济学原理课程逻辑
  - 有中文版本
```

#### 选项 B — xlsx: 成绩分析表

```
【身份】你是一位经济学课程助教，需要处理期中考试成绩。

【任务】使用 xlsx skill 生成一份成绩分析 Excel 文件。

【数据】假设以下分数（可替换为真实数据）：
  学号1-20: 88, 76, 92, 65, 83, 71, 95, 58, 79, 86, 90, 74, 82, 69, 91, 77, 85, 80, 73, 89

【输出形状】一个 .xlsx 文件，包含：
  - Sheet 1 "成绩表": 学号、分数、等级（A:≥90, B:80-89, C:70-79, D:60-69, F:<60）
  - Sheet 2 "统计": 平均分、中位数、标准差、最高分、最低分、及格率
  - Sheet 3 "分布图": 分数段频数分布表
  - 文件命名：midterm-analysis-2026.xlsx

【验收标准】
  - 三个 Sheet 内容完整
  - 等级划定公式正确
  - 统计数据准确
```

#### 选项 C — pdf: 论文摘要

```
【身份】你是一位经济学研究助理，需要为导师快速摘要工作论文。

【任务】使用 pdf skill 读取并摘要一篇经济学工作论文。

【输入】找一篇 NBER 或 SSRN 上的经济学论文 PDF（教师可提前准备），或使用你手头任何英文经济学论文。

【输出形状】一份结构化摘要，包含：
  - 研究问题（一句话）
  - 方法论（一句话）
  - 主要发现（三条）
  - 政策含义（一句话）
  - 你对这篇论文的评价（一个优点 + 一个局限）

【验收标准】
  - 摘要保存为 paper-summary.md
  - 每个部分清晰标注
  - 中文撰写
```

#### 选项 D — canvas-design: 教学海报

```
【身份】你是一位经济学教育设计师，为高中或大一学生设计教学可视化材料。

【任务】使用 canvas-design skill 设计一张"供给与需求"教学海报。

【输出形状】一张海报（PNG 或 SVG），包含：
  - 标题："供给与需求——市场价格如何形成"
  - 需求曲线（向右下倾斜）+ 标注"需求量随价格上升而下降"
  - 供给曲线（向右上倾斜）+ 标注"供给量随价格上升而上升"
  - 均衡点 + 标注"市场出清价格"
  - 用颜色区分两条曲线
  - 文件命名：supply-demand-poster.png

【验收标准】
  - 两条曲线方向正确
  - 标注清晰可读
  - 适合投影或打印使用（A3 尺寸）
```

#### 选项 E — wechat-article-writer: 科普文章

```
【身份】你是一位经济学传播者，运营一个面向大众的经济学科普公众号。

【任务】使用 wechat-article-writer skill 撰写一篇微信公众号科普文章。

【主题】"CPI 到底在测什么？—— 一篮子商品如何测量你的生活成本"

【输出形状】一篇微信公众号格式的文章，包含：
  - 标题（吸引点击，15字以内）
  - 导语（引发好奇，50字以内）
  - 正文（3个小标题，每个200字左右）
  - 至少一个生活化类比（如"CPI 就像记录你家每月买菜账单的变化"）
  - 结尾互动（一个问题引导读者留言）
  - 文件命名：cpi-article.md

【验收标准】
  - 非经济学读者能看懂（不要用公式）
  - 至少一个具体数据例子
  - 有公众号感（不是学术论文感）
```
