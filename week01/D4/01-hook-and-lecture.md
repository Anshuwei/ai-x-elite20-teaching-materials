# Day 4 Hook + 讲义 — "提示词的四步法"

**时长：** Hook 5分钟 + Lecture 15分钟 | **轨道：** T5

---

## Hook（5分钟）— 同一任务，20 种输出

### 操作
提前给全班发同一个任务（D4 前通过微信群发）：

> "请用 AI 工具帮我对这篇经济学短文做摘要。"

给一篇短文（1000字左右的财经新闻或经济学博客）。

### 课堂上展示
- 投屏：挑 5 份差异最大的输出并列展示
- 问："同样的任务，同样的文章，为什么输出差这么多？"
- 答案：**因为每个人写的提示词不同。**
- 有的写了"用中文回复"有的没写，有的指定了字数有的没指定，有的要求分点有的没要求……

### 一句话过渡
> "提示词不是一句随便的话。它是一份工单。今天你学会开工单。"

---

## 讲义（15分钟）— 四步法

### 公式

```
好的提示词 = 身份 + 输入 + 输出形状 + 验收标准
```

### 用经济学场景走一遍

#### ❌ 糟糕的提示词
> "帮我分析一下这个 CPI 数据。"

#### ✅ 四步法版本

```
【身份】你是一位宏观经济学研究助理，擅长用通俗语言向非经济学背景的读者解释经济指标。

【输入】附件是中国近 12 个月的 CPI 月度数据（CSV 格式）。

【输出形状】一篇 800 字以内的中文简报，分三段：
  - 第一段：总体趋势一句话 + 关键数据
  - 第二段：三个主要发现
  - 第三段：一个值得关注的信号 + 一句话政策含义

【验收标准】
  - 非经济学专业读者能看懂
  - 每个发现配一个数据点
  - 不用任何公式
  - 不提"本文""笔者"
```

---

### 四步法拆解

| 步骤 | 含义 | 没有它会怎样 | 经济学例子 |
|------|------|-------------|-----------|
| **身份+受众** | 你让 Agent 扮演谁？写给谁看？ | Agent 用默认风格——可能写成给 CEO 看的但你需要的是给学生看的 | 写给本科生 vs 写给央行官员 vs 写给大众媒体——语调完全不同 |
| **输入** | 你要处理什么材料？给 Agent 什么？ | Agent 用训练数据里的记忆，可能过时或不准确 | 给数据文件 vs 让它凭记忆回答 vs 给它一篇论文 PDF |
| **输出形状** | 输出什么格式？多长？什么结构？ | 输出可能太长、太短、格式不对，需要你回第二遍 | 800字简报 vs 表格 vs 图表描述 vs 邮件草稿 |
| **验收标准** | 什么叫"做好了"？怎么检查？ | 你只能凭感觉判断好坏，Agent 也不知道你的标准 | 每个发现配数据、不用公式、非专业读者能看懂 |

---

### 四步法的经济学命名版（可选）

> 把四步法翻译成经济学研究语境：
>
> - **身份** = 你在分工结构中的位置（委托人给代理人派活）
> - **输入** = 原始数据和材料
> - **输出形状** = 交付物规格（deliverable specification）
> - **验收标准** = 合约里的 performance clause
>
> 一个好的提示词就是一份好的委托-代理合约。

---

### 最重要的心智模型
> **提示词不是一句话。提示词是一个任务说明书。**
> 你给学徒的信息越充分，学徒越不需要猜你的意思。

## Token 钱包提醒（Close 环节，5分钟）

### 概念
> 每一次对话都在花 token。不是烧钱的问题——是烧注意力。你的信息和 Agent 的信息都占 token 预算。

### 决策框架

| 情况 | 策略 |
|------|------|
| 新任务，方向明确 | 写新提示词，用四步法 |
| 类似任务，上次的输出好 | 复用提示词模板，改输入 |
| Agent 理解偏了但方向对 | 在原对话里纠正（不重新开始） |
| Agent 完全理解错了 | 重新写提示词（不在错误线程上继续） |

### 一句话带走
> "Token 很便宜。但重新解释一遍的时间和注意力很贵。开工单之前想清楚四步，就是省钱。"
