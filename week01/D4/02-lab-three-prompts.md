# Day 4 实验 — 三个提示词练习（经济学场景）

**时长：** 35分钟 | **轨道：** T5 + T2

---

## 总体说明

- 每个提示词练习约 10 分钟
- 保存格式：`prompts/D4-P{n}.md`，每个文件包含**完整的提示词 + Agent 的完整回复**
- 三个练习完成后再统一 commit（不是 P1 做完就 commit）

## P1 — 摘要经济学文章（入门）

### 任务
让 Agent 摘要一篇经济学短文。

### 经济学文章素材（可用以下文本替换为你自己的材料）

```text
中国2025年GDP增长5.2%，完成了政府工作报告设定的"5%左右"的预期目标。
从需求侧看，消费对经济增长的贡献率达68%，继续成为增长的第一拉动力；
投资增长4.8%，其中高新技术产业投资增长12.3%，远高于整体；
货物贸易进出口增长6.8%，其中对"一带一路"沿线国家出口增长9.2%。
从供给侧看，服务业增加值占GDP比重升至57.3%，高技术制造业增长8.7%。
居民消费价格指数（CPI）全年上涨0.4%，工业生产者出厂价格指数（PPI）下降1.6%，
显示出有效需求仍不足、部分行业产能过剩的压力。
经济学家指出，2026年宏观政策需要在"稳增长"与"防风险"之间寻求更精准的平衡。
```

### 学生提示词任务

用四步法写一个提示词，让 Agent 把这段文字摘要为：
- 3-4句话
- 面向经济学入门学生
- 包含"需求侧-供给侧-政策含义"三个维度

### 保存为：`prompts/D4-P1.md`

```markdown
# P1 — 经济学文章摘要

## 我的提示词
（粘贴你写的完整提示词）

## Agent 的回复
（粘贴 Agent 的完整回复）
```

## P2 — 撰写经济学教学邮件（中级）

### 任务
你是经济学课程的助教，需要给全班发一封关于"下周期中考试"的邮件。

### 场景信息
- 课程：《宏观经济学原理》
- 考试范围：IS-LM 模型、AD-AS 模型、菲利普斯曲线
- 考试形式：闭卷，选择题 + 一道简答题
- 你需要提醒学生：带计算器、提前15分钟到场、复习重点章节
- 语气：亲切但专业，鼓励学生但不要降低考试严肃性

### 学生提示词任务

用四步法写提示词，特别关注**身份+受众**和**输出形状**这两步。
额外要求：提示词中必须指定一个验收标准是"邮件中不出现任何 AI 味表达（如 delve into, navigate the landscape, in summary 等）"

### 保存为：`prompts/D4-P2.md`

```markdown
# P2 — 经济学教学邮件

## 我的提示词
（粘贴你写的完整提示词）

## Agent 的回复（邮件草稿）
（粘贴 Agent 生成的邮件）
```

## P3 — 探索数据文件结构（进阶）

### 任务
你有一个经济学面板数据文件夹，里面包含多个 CSV 文件。让 Agent 探索这个文件夹的结构并生成一个数据字典。

### 前提准备（学生或教师任选其一）
- **如果有真实数据：** 在工作区放2-3个经济学相关 CSV（如 GDP 数据、CPI 数据、失业率数据）
- **如果是模拟数据：** 在工作区文件夹里创建几个 CSV 文件

### 模拟数据选项（教师提前准备，放入学生工作区或课程仓库）

在 `data/` 文件夹下创建：

```
data/
├── gdp_china_quarterly.csv    （时间、GDP、增长率）
├── cpi_monthly.csv            （时间、CPI、核心CPI）
└── unemployment.csv            （时间、调查失业率、16-24岁、25-59岁）
```

### 学生提示词任务

用四步法写提示词，让 Agent：
1. 列出 `data/` 文件夹中的所有文件
2. 阅读每个文件的前几行，描述变量名和数据类型
3. 生成一个 `data-dictionary.md`，汇总所有文件的字段说明
4. 如果某个文件有缺失，指出并建议补救

### 保存为：`prompts/D4-P3.md`

```markdown
# P3 — 数据文件结构探索

## 我的提示词
（粘贴你写的完整提示词）

## Agent 的回复
（粘贴 Agent 的完整回复，包括它创建的数据字典内容）
```

## 教师巡视要点

| 学生常见问题 | 引导方向 |
|-------------|---------|
| "我不知道怎么写身份" | 问：这段话写给谁看？学生？同事？领导？ |
| "输出形状我写了，但 Agent 没照做" | 检查是不是写了"请"而没有写"必须"或"格式要求："——礼貌性措辞可能被忽略 |
| "P3 我不会，Agent 说看不到文件夹" | 检查文件夹是否在工作区内，是否挂载到了 Cowork |
| 三个都提前做完了 | 让他们试试去掉一个步骤（如去掉身份设定），看输出质量如何变化 |

---

## 经济学教授备注

- P1 的经济学短文你可以替换成你正在研究的论文摘要或教学案例
- P2 的场景贴近你真实的教学角色，学生能看到提示词的即时效用
- P3 的数据探索能力对接后续的实证研究训练——这是未来用 AI 做数据预处理的起点
- 三个提示词的难度梯度故意设计为：纯文本 → 需角色扮演 → 需文件操作 + 结构化输出
