# Day 7 Hook + 讲义 — "K-S-T-A-R 拆解"

**时长：** Hook 5分钟 + Lecture 20分钟 | **轨道：** T5 + T1

---

## Hook（5分钟）— 倒带

### 操作
> "回想昨天我做演示的时候——在我写下第一个提示词之前，我做了什么？"

让学生翻看 observation-journal 的回答。

### 引导序列（快速点名）
1. "我知不知道这篇论文的主题？" → **有**（即使不精确）
2. "我知不知道备忘录要给谁看？" → **有**（学院同事）
3. "我知不知道好的备忘录长什么样？" → **有**（7部分结构）

### 揭示
> "这三个'知道'对应 K-S-T-A-R 的前三个字母——K、S、T。昨天你们看到的是 A（行动）和 R（回顾）。但 K-S-T 在写任何一个字之前就已经发生了。**好的 AI 使用者把一半的时间花在 K-S-T 上，另一半花在 A 上，最后把 R 存进下一次的 K 里。**"

---

## 讲义（20分钟）— 五个字母，五个类比，五个经济学对应

### K — Knowledge（知识）：你的图书馆

| 问题 | "关于这个任务，我已经知道了什么？" |
|------|-------------------------------------|
| **类比** | 你走进图书馆之前，脑子里有的东西——你知道分类法、知道哪几本书是权威、知道这个问题在文献里的位置 |
| **没有 K 会怎样** | 你不知道 Agent 给的答案是对是错、是深是浅。你失去了判断力。 |
| **经济学对应** | 你知道最低工资对就业影响的理论争议（新古典 vs Card-Krueger），所以你看到 Agent 片面引用一种观点时会警觉 |
| **K 来自哪里** | 你的专业训练、你读过的论文、你教过的课、你上次做类似任务的经验（R→K 循环）|
| **在提示词之前** | 花 2 分钟写下"关于这个任务，我已经知道的三件事" |

---

### S — Situation（情境）：你站在哪里

| 问题 | "现在的具体情境是什么？有什么约束？" |
|------|-------------------------------------|
| **类比** | 你用手机地图导航——你需要告诉地图你现在在哪、你要去哪、你是开车还是走路 |
| **没有 S 会怎样** | Agent 生成的东西可能很正确，但在你的情境中用不了——格式不对、语气不对、受众不对 |
| **经济学对应** | "我要给大一学生解释 IS-LM" vs "我要给同行展示 DSGE 模型的脉冲响应结果"——同样的经济学原理，完全不同的情境要求 |
| **S 包含什么** | 时间约束、受众、格式要求、工具可用性、你对该领域的熟悉程度 |
| **在提示词之前** | 花 1 分钟写下"谁会用这个产出？在什么场景下用？有什么限制？" |

---

### T — Task（任务）：你下的工单

| 问题 | "具体要产出什么？怎么判断做好了？" |
|------|-------------------------------------|
| **类比** | 你给装修师傅下的工单——不是"把厨房弄好"，而是"厨房台面换成石英石，尺寸 240×60cm，颜色米白，周四前完成，验收标准是无明显接缝" |
| **没有 T 会怎样** | Agent 给你一个合理但不合用的东西——你浪费了一轮迭代 |
| **经济学对应** | 不是"分析这个数据"，而是"用固定效应模型分析这个面板数据，报告系数、标准误、显著性，输出一张包含三列（变量名、系数、p值）的表格" |
| **T 包含什么** | 输出格式、长度、结构、必须包含的元素、验收标准（越具体越好）|
| **在提示词里** | 这就是四步法中的"输出形状"+"验收标准"——T 是 Ask 动作的核心 |

---

### A — Action（行动）：执行 + 迭代

| 问题 | "我怎么执行？看到输出后我怎么调整？" |
|------|-------------------------------------|
| **类比** | 你看学徒做第一版，不说话，等做完再看哪里需要改。第二遍是"这里深一点，那里轻一点"——你在转方向盘 |
| **没有 A 中的迭代会怎样** | 你接受了一个"看起来还行"但实际有问题的输出——验证成本后移到使用时才发现 |
| **经济学对应** | 你跑回归，看系数符号——如果跟理论预测相反，你不会"换一个全新的模型"，你会检查是否遗漏了控制变量、是否需要不同的标准误聚类。这是迭代。 |
| **A 的两部分** | A1（执行提示词）+ A2（阅读输出，决定是否需要迭代）+ A3（迭代指令）+ …… |
| **关键习惯** | 不要在 A1 之后就停下来。至少做一次"读输出 → 找问题 → 给修正指令"的循环。 |

---

### R — Review（回顾）：存回图书馆

| 问题 | "我从这次循环中学到了什么？这个经验怎么存进我的 K？" |
|------|-----------------------------------------------------|
| **类比** | 你在实验笔记本上写"这次用了 XX 方法，下次改用 YY 会更好"——这本笔记本是你的 K 在增长 |
| **没有 R 会怎样** | 你每次做类似任务都从零开始——没有积累，没有加速度 |
| **经济学对应** | 你做完一篇论文后会写一个"lessons learned"——哪个数据源好、哪个变量测度有问题、哪个审稿人提了关键意见。这些"lessons"进入你的研究能力 K |
| **R 包含什么** | 这次提示词的哪个部分最有效？Agent 在什么地方反复犯错？什么是我现在知道了而今天之前不知道的？ |
| **在任务完成后** | 花 3 分钟写一个 R 笔记——保存到你的"提示词经验库"里 |

---

## K-S-T-A-R 环形图

```
        K（你的知识）
       /            \
      /              \
     R（回顾）         S（情境）
      \              /
       \            /
        A（行动）← T（任务）
         ↑          |
         └──────────┘
         （迭代回路）
```

### 环形不是线性的含义

> K-S-T-A-R 不是"做完五步就完了"——R 的输出进入下一次的 K，下一次的 S 更精确，下一次的 T 更清楚，下一次的 A 更快。**你转的圈数越多，每一圈越快、越深。** 这就是 AI+X 精英班里"精英"二字的含义——不是一次做对，是每圈比上一圈好。

## 和 D6 IAIV 的关系（一张表讲清楚）

| IAIV（D6） | K-S-T-A-R（D7） | 关系 |
|------------|-----------------|------|
| Intent | K + S + T | IAIV 把"思考阶段"并成一个词（Intent），KSTAR 把它拆成三块 |
| Ask | T 的"写提示词"部分 | T 是完整的任务规格，Ask 是把它翻译成 Agent 能读的提示词 |
| Iterate | A 中的"迭代" | 同一个东西 |
| Verify | R | 同一个东西 |

> "IAIV 是日常用的快速心智模型。K-S-T-A-R 是反思用的完整框架。日常用 IAIV 不迷路，复盘用 K-S-T-A-R 不遗漏。"

---

## 经济学教授备注
- K-S-T-A-R 可以类比为经济学实证研究的标准流程：K=文献综述+理论框架，S=研究设计（数据可得性、时间约束），T=模型设定（方程形式、变量选取），A=跑回归+稳健性检验，R=结果讨论+下一步研究方向
- 这种类比让学生看到：**他们已经在做 K-S-T-A-R 了，只是之前没有用这个名字，也没有把 AI 嵌入其中**
